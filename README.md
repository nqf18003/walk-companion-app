# 散歩仲間（スマホ用ウェブアプリ）

### [▶ アプリを開く](https://nqf18003.github.io/walk-companion-app/)
Android の Chrome で開いてください。

Android の Chrome で開いて景色の写真を撮ると、Claude が散歩仲間として話しかけてくれます。

## 使い方
1. ページを開く（「🎤 会話」を初めて使うときはマイクの使用を許可する）
2. 右下の ⚙ で Claude の API キーを入力して「保存」
   - キーはこのスマホのブラウザの中（localStorage）だけに保存され、コードには含まれません
3. 写真は、設定の「写真のモード」で 2 つのやり方を選べます
   - **ボタンで撮る**（初期値）…「📷 写真」を押すとスマホのカメラが開くので、撮って OK（✓）を押すとその写真を Claude に送り、返事を読み上げます。カメラは撮るときだけ動くので、電池をあまり使いません
   - **自動で撮る** …「▶ 開始」を押すとカメラがつき、すぐに 1 枚、その後は設定した間隔（初期値 1 分）ごとに今の景色を撮って送ります。「■ 停止」でカメラも止まります。会話中に話しかけると、そのときの景色も一緒に送ります（設定で止められます）。Claude が考え中・読み上げ中・こちらが話している途中は、その回は撮りません
   - どちらのモードでも、画面の上には最後に撮った写真（自動で撮影中はカメラの映像）が出ます。写真は会話の中にも残り、押すと大きく見られます
   - 撮った写真は、スマホの「ダウンロード」フォルダに保存されます（設定で止められます）
   - 写真の欄の右上の「🔄 外カメラ／内カメラ（自撮り）」ボタンで、使うカメラを切り替えられます。自動で撮影中でもすぐに切り替わります。「ボタンで撮る」では、切り替えたほうのカメラでカメラアプリが開きます（機種によっては、カメラアプリの中で切り替えが必要なこともあります）
4. 「🎤 会話」… 押すと会話モードになり、ずっと声を聞き続けます（もう一度押すと終了）
   - 話が途切れたところで、話した言葉（文字）を Claude に送り、返事を読み上げます（「ボタンで撮る」モードでは写真は送りません）
   - Claude が読み上げている途中でこちらが話し始めると、読み上げを止めて聞きます
   - Claude が考えている間に話したことは、返事のあとに続けて送ります
   - 写真を撮ってカメラから戻ると、また聞き始めます
5. 文字で話しかける … 声を出せないときは、下の入力欄に書いて「送信」（またはキーボードの送信）を押すと、文字で送れます。返事は今までどおり読み上げます。「自動で撮る」モードで撮影中は、今の景色も一緒に送ります（声のときと同じ設定）

## 設定
- モデル: 初期値は Claude Opus 5.5。料金を抑えたいときは Claude Haiku 5.5 を選んでください
- 写真のモード: 「ボタンで撮る」か「自動で撮る」か
- 自動で撮る間隔（分、0.5 分以上）
- 自動のとき、話しかけたら今の景色も一緒に送る: 初期値はオン（「ボタンで撮る」のときは、話しかけても写真は送りません）
- 撮った写真をスマホに保存する: 初期値はオン。ファイル名は `walk_日付_時刻.jpg`
- 写真の大きさ（Claude に送るとき）: 長い辺 384 / 512 / 768 ピクセル（JPEG 品質 0.6 に縮めて送ります）
- 読み上げの声: スマホに入っている読み上げの声から選べます（Claude の API には声の機能がないため、スマホの声を使います）。声を増やすには Android の設定 →「テキスト読み上げ」で Google の音声データを追加してください
- 声の高さ: 低くすると男性っぽく、高くすると女性っぽくなります
- 読み上げの速さ（「🔊 声を試す」で保存前に聞けます）
- 「会話をリセット」で、それまでのやりとりを忘れます
- 「トークン合計をリセット」で、トークンの合計を 0 に戻します

## トークンの表示
写真の欄の左下に、使ったトークンと料金の目安を出します。
- 今回: 直前の 1 回の入力・出力トークン（出力には Claude が考えた分も含みます）
- 合計: リセットしてからの合計トークン（スマホに保存されるので、ページを閉じても残ります）
- 円は 1 ドル 150 円で計算した目安です。正確な金額は Claude Console で確認してください

## 仕組み
- 直前の 6 往復をそのまま送り、それより前の Claude の発言は「くり返さない話題メモ」として短く送ります
- 写真はそのとき撮った 1 枚だけを送ります。前に送った写真を送り直すことはありません（料金を抑えるため）
- ボタンを一度押したあとは、画面が消えないようにしています（Wake Lock）
- サーバーは使わず、スマホから Claude API に直接つなぎます

## うまくいかないとき
- 会話モードでは、スピーカーから出た Claude の声をマイクが拾うことがあります。似た言葉は無視するようにしていますが、イヤホンを使うといちばん確実です
- Android では、聞き始めるたびに「ピッ」と音が鳴ることがあります（Chrome の仕様で、ページからは消せません）
- 写真を保存するときに「複数のファイルをダウンロードしますか」と聞かれたら「許可」を押してください
- 「自動で撮る」はカメラをつけたままにするので、電池を多く使います。また写真の保存をオンにしていると、撮るたびにダウンロードフォルダに写真が増えます
- 保存した写真は「ファイル」アプリの「ダウンロード」で見られます。Google フォトで見るには、フォトの「ライブラリ」→「デバイス内の写真」で Download フォルダを表示してください

## プライバシー（データの行き先）
| もの | 保存される場所 | 外に送られるか |
|---|---|---|
| API キー | スマホの Chrome の中だけ | Claude に問い合わせるときに Anthropic にだけ送る |
| 撮った写真（元の大きさ） | スマホの「ダウンロード」フォルダ（保存がオンのとき） | アプリからは送らない |
| Claude に送る写真（縮めたもの） | 残さない | Anthropic に送る（作り直すので位置情報は入らない） |
| 会話 | 画面の中だけ（ページを閉じると消える） | 直前のやりとりを Anthropic に送る |
| 声 | 残さない | 文字にするために Chrome の音声入力の仕組みで Google に送られる |
| 設定・トークンの合計 | スマホの Chrome の中だけ | 送らない |

- アプリが通信する相手は `api.anthropic.com` だけです。外部のスクリプト・アクセス解析・広告は使っていません
- Anthropic は API で受け取った内容を学習に使わず、30 日以内に削除します（安全上の問題で検出された場合は最長 2 年）。[Anthropic の説明](https://privacy.claude.com/en/articles/7996866-how-long-do-you-store-my-organization-s-data)
- 読み上げの声に Google のネットワーク音声を使っている場合、読み上げる文が Google に送られることがあります
- 保存した元の写真には撮影場所（GPS）が残ることがあります。Google フォトで Download フォルダのバックアップをオンにしていると、自分の Google アカウントにアップロードされます
- 同じ `nqf18003.github.io` で公開する別のページからは、このアプリの保存内容（API キーを含む）を読めます。このアドレスで、信頼できない外部スクリプトを使うページを公開しないでください
